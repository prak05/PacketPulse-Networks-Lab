# PacketPulse Networks Lab

Curated coursework implementations and supporting documents from Prakhar Sharma's CSE lab work.

This repository preserves the source exercises for the subject and excludes generated binaries and machine-local outputs.

## Portfolio brief

A networking laboratory collection covering protocols, socket programming, routing, flow control, and traffic-management exercises.

### Visual system

Signal-map presentation: cool neutral surfaces, blue packet traces, topology diagrams, and status-led documentation.

### Run and output

Run experiments on localhost or an isolated lab network. Document ports, assumptions, packet flows, and cleanup steps.
